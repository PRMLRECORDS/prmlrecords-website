# PRML Media Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Because this edits the live PRML website, the IMPLEMENTATION SKILL for all HTML/CSS work is **prml-website-design** (brand lock), and the build exits through **prml-cache-bust** → **prml-deploy** (SEAUX9 approval gate).

**Goal:** Turn `media.html` from a "Coming Soon" page into a live media hub — merged player + curated Video/Audio/Photos gallery with Chromecast/AirPlay casting, a public creator sign-up form, an unlisted internal intake form for Quo, and AdSense monetization on the media + blog pages.

**Architecture:** Static HTML/CSS/JS site. The proven player + casting code already exists in `player.html`; we lift it into `media.html` and drive it from a new curated list file `js/media-data.js`. Both forms POST to the existing Google Apps Script Forms Kit endpoint with new `action` values. AdSense rolls out in two phases: loader site-wide for verification, then ad units on media + blog only.

**Tech Stack:** Plain HTML5, CSS, vanilla JS. HTML5 `<video>`/`<audio>`, WebKit AirPlay, Google Cast SDK + Remote Playback API, Google Apps Script (Forms Kit), Google AdSense.

(function(){
  const GAS_URL='https://script.google.com/macros/s/AKfycbzlXsUJFb36zh58jc2-N54Cmfhgh4EC478OzKehJG56qeNcZRSzFmOAU4PBHEgVdzsLyQ/exec';
